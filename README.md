# PHP-Game-and-Watch-Collection
A hobby project / Friends favour

info: 
- A Game and Watch is a nintendo console/handheld of the 1980 - 1990's.

A good friend has a massive Nintendo Game and Watch collection. So massive, that he was losing track of his collection.
He asked me to build him a web app around his collection, so i gladly did!

Important:
- I won't be sharing any database files.
- The images/GameAndWatches folder is emptied

  I respect his privacy and won't show his belongings. That's why i decided to not include any information about the personal collection.
  Getting the app to work on your device could make it harder. However, my goal is to share my code in this repository, not an app that's ready to use for others.


Features:
- A list of all the Game and Watches in the collection (SELECT)
- Clicking on the "meer info" button on a Game and Watch shows more information about it. Such as a description, if it's complete, boxed, and a price charting URL.
- Clicking on the "wijzigen" button on a Game and Watch gives you the ability to change all of that information. (UPDATE)
- Clicking on the "verwijderen" button deletes the Game and Watch (DELETE)
- Clicking on the "toevoegen" button lets you add a new Game and Watch to the list (INSERT)

With only one table, it's one of the easiest types of a CRUD system. Because most of the data would differ between the Game and Watches, I decided not to create any additional tables.
The app is not responsive, because my friend said he'd only use his computer for the app.

I'm quite proud of the result and to have helped out!
